โลโก้สาขาวิชา

โค้ดhtml
  1. <img src = "images/campus.jpg" alt = "ภาพมหาวิทยาลัย" width = "220" >
  2. <img src = "images/student.jpg" alt = "นักศึกษากำลังเรียน" width = "180" >
  3. <img src = "images/logo.png" alt = "โลโก้วิชา" height = "80" >

🎯 จุดประสงค์การเรียนรู้

  1. อธิบายการใช้งานแท็ก <a> เพื่อสร้างลิงก์ไปยังหน้าเว็บหรือแหล่งต่างๆ
  2. แทรกรูปภาพลงในหน้าเว็บโดยกำหนดคุณสมบัติพื้นฐาน
  3. ตกแต่งลิงก์และรูปภาพด้วย CSS เพื่อความสวยงามและน่าใช้งาน

🏷️ แท็กที่ใช้บ่อย

<a> href target <img> src alt width height

📝 กิจกรรมฝึกปฏิบัติ

  1. สร้างลิงก์อย่างน้อย 3 แบบ
  2. แทรกรูปภาพอย่างน้อย 2 รูป
  3. ใส่ alt ให้กับรูปภาพทุกภาพ
  4. ใส่ CSS เปลี่ยนสีลิงก์เมื่อ hover
  5. ตกแต่งรูปภาพด้วย border-radius หรือ box-shadow
  6. บันทึกไฟล์ชื่อ "link-image.html"
